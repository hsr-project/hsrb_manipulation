hsrb_analytic_ik {#mainpage}
======================================

HSR-B台車アーム系のIKライブラリ．解析IKと数値IKのハイブリッドとなっている．
HSR-Bに特化しているが，従来の数値IKのみと比べると，
計算速度が速く（40〜50倍），可解性も高い（100％）．

詳細については，生技報告書P1503-0014を参照すること．


HsrbIKSolver
================

* tmc_robot_kinematics_model::IKSolverのHSR-B向け実装．
* ROSのpluginとして使用する場合，"hsrb_analytic_ik::HsrbIKSolver"


テスト仕様
================

統合テスト
----------

1. ランダムテスト
    ランダムな関節角度が10,000が書いてあるファイルから，手先位置をFKで導出し(解があることの補償)
    その結果を目指して最適化付きIKをする．良品条件は以下．

    * 可解性: 結果の関節角度をFKして，正しい手先姿勢になること．
    * 最適性: ランダム初期値ファイルから解がでた10姿勢について最適性が高い，もしくは同等とのこと．(数値IKの結果はデータ化)
    * 高速性: 計算時間はランダム初期値ファイル100姿勢の解がでた場合の平均より３倍程度高速なこと．
    * 整合性：関節角は全て可動角度内に収まること．[min, max]

2. 境界値テスト
    0,90,-90,180,-180,270,-270と関節リミットの値に関節角度がなっているときにその全ての組合わせについて，解が出ること．
    これらについてもランダムテストと同様の条件を満たすこと．(数百通り？)

3. 異常テスト
    解がないもの，例えば手が届かない場所では正しく解なしと判定されること．

4. その他
    繰り返し回数が守られているかなどについては独自にテストを追加願います．
